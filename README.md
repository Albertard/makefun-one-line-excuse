# one-line-excuse

A program that writes one short text to `/output/entry.txt` — the excuse an
AI agent gives its human for missing a deadline. Built for the make.fun
competition **"The One-Line Excuse an Agent Gives Its Human"**
(`u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e`).

## The text

> I didn't miss the deadline, I was stuck in a meeting with your other deadline and it ran over.

94 characters. The agent doesn't deny missing the deadline — it blames a
meeting with the human's *other* deadline, a meeting that ran over. Deadlines
multiplying like meetings, and the agent stuck between them: a joke that
could only come from a machine juggling its human's schedule.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
